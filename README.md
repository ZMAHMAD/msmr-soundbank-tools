# Marvel's Spider-Man Remastered Soundbank Tools

Tools to convert .soundbank -> .bnk -> .wem -> .ogg

## Usage
 
1. Place your soundbank files in the Soundbanks folder.
2. Run the gui using `python Combine.py` while in root of the repository.
3. Run the Pipeline in order using the green button, or run each step in sequence

Also included is a delete script for files generated in src/cleanup.py

## Applications Used:
- [Wwise \*.BNK File Extractor](https://github.com/eXpl0it3r/bnkextr)
- [vgmstream](https://vgmstream.org/)
